## 1. Идея одним абзацем

До коммита был только симулятор (`index.html` = кнопки, инпут, список последовательности). Новичок открывал страницу и не понимал: что такое Коллатц? Что вводить? Зачем?

После коммита появилась воронка как в нормальных продуктах:

```
index.html (Главная / Лендинг) ──[Запустить]──> simulation.html (Симулятор)
        │                                            ▲
        │──[Как это работает]──> guide.html          │ prefill через sessionStorage
        └──[О проекте → ?tab=about]──┘               └──[Back]──┘
```

Плюс на всех трёх страницах — **общий экран загрузки** с цитатами и **двуязычность RU/EN**.

Ключевой принцип коммита: **логику симулятора не трогать**. Все новые модули только оборачивают её снаружи.

## 3. `index.html` — Главная страница

### Что видит пользователь
1. Огромный заголовок `COLLA` (градиент) + `TZIUM` (белый). Размер `clamp(3rem, 13vw, 8.5rem)` — от телефона до монитора.
2. Слоган: *«Любое число. Один закон. Всегда единица?»*
3. Три пилюли-правила: `Чётное — делим на 2 / Нечётное — ×3+1 / Повторяем до 1`.
4. Карточка: лейбл `Введите число`, инпут (по умолчанию `27` — классика, у 27 длинная красивая траектория из 111 шагов), красная строка ошибки, большая градиентная кнопка `Запустить`, под ней две вторичные ссылки.
5. В углу — кнопка языка `RU/EN`. На фоне — мерцающие звёзды. При первом заходе — лоадер поверх всего.

### Технические детали
- `lang="ru"` (в коммите; позже сменили на `en` по умолчанию), `theme-color #0b1020`, `description` для SEO.
- `<style>@view-transition { navigation: auto; }</style>` — включает кросс-документные View Transitions там, где браузер умеет. Прогрессивное улучшение: если не умеет — просто обычная навигация.
- Все тексты через `data-i18n="home.*"` — их переписывает `i18n.js`. У плейсхолдера инпута отдельный трюк: `data-i18n-attr="placeholder"`.
- Подключает ровно 3 модуля, симулятор не грузит вообще:
```html
<script src="./ESmodules/shared/i18n.js" type="module"></script>
<script src="./ESmodules/shared/loader.js" type="module"></script>
<script src="./ESmodules/landing/landing-main.js" type="module"></script>
```

## 5. `guide.html` — Страницы с объяснениями

Каркас intentionally пустой: вся «мякоть» рендерится из `guide.js`. В HTML только:

- Лоадер + звёздный фон (как везде — единый визуальный язык).
- Кнопка `Назад → index.html` со стрелкой SVG.
- Заголовок `Гипотеза Коллатца` (`data-i18n="guide.title"`).
- Три таба: `Простое объяснение / Правила / О проекте`.
- Пустой `<article id="guide-article">` — сюда JS вставляет HTML.

Фишка: **глубокие ссылки**. С главной `О проекте` ведёт на `guide.html?tab=about` — гайд сам парсит `URLSearchParams` и открывает нужный таб. Так можно ссылаться на конкретный раздел.

### Три таба изнутри (`guide.js`, 155 строк)

**Tab `simple` — «Что это вообще такое?»**
Формула-бейдж:
```
f(n) = n/2 (чётное) | 3n+1 (нечётное)
```
где `n/2` зелёный, `3n+1` синий. Дальше — честный рассказ: проверить до `2⁶⁸` ≠ доказать, хаос траекторий, цитата Эрдёша *«Математика ещё не готова к таким задачам»* в красивой плашке, метафора «чёрная дыра для целых чисел → цикл 4→2→1». Всё в двух языках.

**Tab `rules` — «Как пользоваться программой»**
Список режимов: `Мгновенно / Авто / Вручную (Z добавляет, X убирает)` + сетка хоткеев `Space, F, R, 1/2/3, Z/X` в виде `<kbd>`-плашек.

**Tab `about` — «О проекте»**
Абзац про любопытство и хаос + градиентная кнопка `Veritasium — Самая опасная задача (youtu.be/094y1Z2wpJg)` + plain-кнопка `GitHub`.

Переключение табов — без перезагрузки: `currentTab` + `paint()` (класс `is-active`) + `renderPanel()`. Смена языка (`langchange`) перерендеривает статью автоматически.

## 6. `landing-main.js` — Мозг главной (125 строк)

Порт `HomePage.tsx` из Astra на ванильный JS. Четыре функции:

### 6.1. `buildStars(90)` — звёздное небо за 15 строк
Создаёт 90 `<span class="clz-star">` со случайными `top/left/size 1-3px/--delay/--dur`. Анимация мерцания — чистый CSS (`clz-twinkle`). Дёшево, красиво, один `DocumentFragment` — один reflow.

### 6.2. `reveal()` — появление блоков
Если есть `window.anime` (подключён `anime.min.js`): `opacity [0→1], translateY [20→0], stagger 120ms`. Если нет — fallback на CSS-класс `reveal-in` через `setTimeout`. Двойная надёжность.

### 6.3. `initInput()` — валидация до 10¹⁰⁰
```js
const clean = raw => raw.replace(/[^\d]/g,'').replace(/^0+(?=\d)/,'').slice(0,101);
```
- Режет всё не-цифровое на лету (буквы просто не вводятся).
- Срезает ведущие нули (`007` → `7`).
- Лимит 101 цифра = `10¹⁰⁰` (гугол). Симулятор работает на BigInt, так что большие числа — не баг, а фича.
- Пусто → `Поле пустое`, `0` или мусор → `Введите целое положительное число` (через `t()`, т.е. на текущем языке). Ошибка подсвечивает инпут классом `is-error`.
- Успех → `sessionStorage.setItem('collatz-start', value)` → `navigate('simulation.html')`. `Enter` тоже запускает.

### 6.4. `navigate()` + `initLang()`
`navigate` — умный переход: если браузер умеет MPA View Transitions (`@view-transition`), достаточно `location.href`; если только старые same-document — оборачивает в `document.startViewTransition()`. Детект через `CSS.supports('view-transition-name: none')`.
`initLang` — кнопка-переключатель `RU↔EN`, текст кнопки = `getLang().toUpperCase()`.

## 7. `shared/i18n.js` — Мини-система переводов (121 строка)

Выжимка из `Astra_Collatz/translations.ts`, только для лендинга/гайда/лоадера. Симулятор специально оставлен английским.

- `KEY='collatz-lang'`, `DEFAULT_LANG='ru'` (в этом коммите русский; позже стал `en`).
- `translations = { ru: {...20 ключей}, en: {...} }` — ключи вида `home.tagline`, `guide.tab.simple`, `error.empty`.
- `load()` — читает `localStorage`, переживает приватный режим (`try/catch`).
- `setLang()` — пишет в `localStorage`, ставит `<html lang>`, вызывает `applyTranslations()`, кидает `CustomEvent('langchange')` — на него подписан гайд.
- `applyTranslations()` — пробегает все `[data-i18n]`, ставит `textContent` или атрибут (`placeholder`).
- `QUOTES[5]` — англоязычные афоризмы для лоадера (Эрдёш, «black hole for integers»...).
- При импорте сразу ставит `lang` и переводит страницу (с учётом `readyState`).

## 8. `shared/loader.js` — Экран загрузки (64 строки)

Самый атмосферный компонент коммита. Разметка живёт в каждом HTML, логика — общая.

**Жизненный цикл:**
1. `t0 = performance.now()` в момент импорта (почти старт навигации).
2. Сразу показывает случайную цитату (`pickQuote()`), перезапускает fade-in анимацию через `void offsetWidth` трюк.
3. Каждые 2 сек меняет цитату (`setInterval`).
4. Ждёт `window load` + `document.fonts.ready` (но не дольше 1.5 сек — `Promise.race`), затем ждёт до **минимума 2 сек** на экране (`MIN_VISIBLE_MS`).
5. Добавляет `loader-hidden` (CSS `opacity 0, 500ms`), после `transitionend` делает `overlay.remove()` + fallback-таймер `700ms` на случай, если событие не выстрелит.
6. Если `#loader-overlay` нет — модуль no-op, ничего не ломает.

**Визуал (`landing.css`):** `fixed inset-0 z-100 #0b1020`, два кольца спиннера (внешнее `0.9s`, внутреннее `1.4s reverse`), заголовок `COLLATZIUM` с `letter-spacing 0.3em`, курсивная цитата `#9fb0d8`.

Зачем минимум 2 сек? Чтобы лоадер не мигал на быстрых машинах и пользователь успевал прочитать цитату. Осознанное UX-решение, а не тормоз.

## 9. `shared/prefill.js` — Мостик в 30 строк

```js
value = sessionStorage.getItem('collatz-start'); // забрали
sessionStorage.removeItem(KEY);                   // почистили
input.value = value;                              // подставили
input.dispatchEvent(new Event('input',{bubbles:true})); // «как будто напечатал»
```

- `sessionStorage` (а не `localStorage`) — значение живёт одну навигацию и само исчезает при закрытии таба. Чистится сразу после чтения, чтобы повторный заход в симулятор не тащил старое число.
- Не авторанит, не дёргает `main.js` напрямую — только имитирует ввод. Симулятор реагирует штатным путём.
- Валидация `/^\d+$/`, `try/catch` на приватный режим, guards на отсутствие инпута.
